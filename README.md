# Gitarrentrainer

Gitarren-Übungs-App mit Tonerkennung übers Mikrofon, Tabs mit automatischem Weiterscrollen, Stimmgerät und einem Coach, der Tempo und Schwierigkeit anpasst.

Live: https://philipmerten85-jpg.github.io/gitarrentrainer/

Auf dem iPhone in Safari öffnen → Teilen → „Zum Home-Bildschirm“.
